# Final Portfolio Project - my portfolio site 
## 📂 About project:
Project created using ```react.js``` web framework with ```TypeScript``` 
This project is my ```portfolio site``` where I show my projects, learned skills and achivements in my ```IT carrier```   
I have many portfolio websites this is my final version  

Portfolio site is ```continuously updated``` for new things, projects, skills, certificates  
## ⚙️ Run project:  
To run this project you must have installed ```node.js``` and ```npm```  
- Clone this repository using:
```
git clone https://github.com/kkamildev/final-portfolio-project.git
```
- Enter to cloned repository and install dependencies using:
```
npm install
```
- Finally run project using: 
```
npm run dev
``` 
- Vite server should host project on ```localhost:5173```
